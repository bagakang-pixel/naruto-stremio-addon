Cara pakai:
1. Isi TorBox API key (opsional tapi direkomendasikan untuk streaming langsung).
2. Klik Install to Stremio — Stremio akan terbuka dan menambahkan addon.
3. Buka kategori Naruto Ocean Cut di Stremio → pilih episode → klik stream TorBox.

Tanpa API key: addon mengembalikan infoHash torrent. Anda tetap bisa memutar lewat addon torrent lain (Torrentio, dll) atau lewat Stremio torrent engine.
